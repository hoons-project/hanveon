# Hanveon — 생김새 기준

화면·색·글씨·짜임을 바꾸기 전에 이 문서를 읽고 여기에 맞춘다.
애매하면 이 문서가 이긴다.

## 한 줄로

**「조용한 흰 벽에 산호색 표시 하나」.** 에어비앤비 쪽 짜임이다.
바탕은 흰색이고, 그림(게임 그림)이 주인공이다. 테두리와 그림자는 거의 안 쓴다.
색은 **거의 안 쓴다** — 검정에 가까운 글씨색과 흐린 회색이 거의 전부다.

> **2026-08-22에 통째로 바꿨다.** 그전에는 「종이에 그린 장난감 오락기」였다 —
> 두꺼운 잉크 테두리, 크림 바탕, 밀린 그림자, 쪽마다 다른 바탕색.
> 그건 이제 **게임 캔버스 안쪽에만 남아 있다.** 아래 「게임 안쪽」을 본다.

## 색

**색은 하나뿐이다.** 산호(Rausch)는 로고에만 쓴다. 그 밖에는 회색 계열만 쓴다.

| 이름 | 값 | 어디에 |
|---|---|---|
| 산호 | `#FF385C` | **로고의 `veon` 한 곳.** 다른 데 쓰지 않는다 |
| 산호 진한 | `#E00B41` | 산호를 누르거나 올렸을 때 |
| 글씨 | `#222222` | 모든 글씨, 아이콘, 어두운 단추 바탕. **순검정은 안 쓴다** |
| 흐린 글씨 | `#6A6A6A` | 설명글, 곁들이는 글, 발 |
| 아주 흐린 글씨 | `#C1C1C1` | 꺼진 것, 자리 표시 |
| 실선 | `#EBEBEB` | 머리카락처럼 얇은 줄. 칸 사이, 발 위 |
| 옅은 바탕 | `#F7F7F7` | 발 바탕, 올렸을 때 바탕, 둥근 단추 바탕 |
| 흰색 | `#FFFFFF` | 쪽 바탕, 덮개 화면 바탕 |

**하지 않는 것** — 산호를 글씨·바탕·꾸밈에 쓰는 것, 색을 하나 더 들이는 것.

크림 `#FFF7EA` 은 **게임 쪽 노는 자리에만** 쓴다.
해 `#FFD23F` 와 잉크 `#2A3145` 는 게임 쪽과 **대문 목록 카드**에 쓴다.

## 글씨

- 차례 — `Inter Variable` → `Pretendard` → 시스템 글꼴.
  Inter 는 **우리 저장소에서 내보낸다** (`@fontsource-variable/inter`).
  **구글 글꼴 주소에서 받아오지 않는다** — 방문자 IP가 구글로 넘어가서 유럽 개인정보법에
  걸린다. 한글·일본말·중국말은 뒤 차례가 받는다
- 몸글 **14px / 400**, 줄 사이 1.43. 이게 기본이다
- 화면 조작 글 **16px / 500**
- 작은 제목 **20px / 600**
- 칸 제목 **22px / 500**, 자간 `-0.02em`
- 쪽 제목 **28px / 700**
- **12px 아래로 내려가지 않는다.** 11px 은 아주 작은 표시에만
- **700(굵게)은 쪽 제목에만.** 몸글과 곁들이는 글은 400~600
- `h1` `h2` 에 `word-break:keep-all` 을 꼭 넣는다. 안 넣으면 중국말·일본말 제목이 글자 가운데서 잘린다
- 숫자는 `font-variant-numeric:tabular-nums`

## 모서리

| 무엇 | 값 |
|---|---|
| 목록 그림, 캔버스, 덮개 화면 | `12px` |
| 나라말 고르는 칸, 단추, 둥근 단추 | `9999px` (알약) |
| 네모 단추 | `8px` |

## 그림자

**거의 안 쓴다.** 딱 두 군데만 쓴다 — 덮개 화면의 부드러운 그림자와,
**오락기 쪽의 딱 떨어지는 밀린 그림자**(게임 노는 자리, 대문 목록 카드).

| 어디 | 값 |
|---|---|
| 덮개 화면 (시작·끝·멈춤) | `0 8px 28px rgba(0,0,0,.28)` |
| 오락기 (게임 통 · 대문 카드 · 노란 단추) | `8px 8px 0` · `0 5px 0` — 흐림 없이 |
| 살짝 띄운 것 | `rgba(0,0,0,.02) 0 0 0 1px, rgba(0,0,0,.04) 0 2px 6px, rgba(0,0,0,.1) 0 4px 8px` |

## 사이 띄우기

기본 단위 **4px**. 쓰는 값 — 4 · 8 · 12 · 16 · 20 · 24 · 28 · 32 · 40 · 48.
칸과 칸 사이 12px, 덩어리와 덩어리 사이 48px. 쪽 최대 너비 1120px, 양옆 여백 24px.

## 단추

```css
button{                      /* 주된 단추 */
  background:#222222; color:#fff;
  border:0; border-radius:9999px;
  font-size:16px; font-weight:500;
  padding:13px 26px;
}
button.ghost{                /* 곁들이는 단추 */
  background:transparent; color:#222222;
  border:1px solid #222222; border-radius:8px;
}
```

**누르는 느낌은 색으로 낸다.** 아래로 내려가는 움직임은 안 쓴다.

## 짜임

- 머리 — 왼쪽에 **햄버거 목차**와 로고, 오른쪽에 나라말 칸. 아래에 얇은 줄.
  목차에는 게임 목록이 들어가고, 그 아래 줄 하나로 나뉘어 읽는 쪽 다섯이 붙는다
- 대문(넓은 화면) — 쪽 제목 → 한 줄 설명 → **작은 오락기 카드 격자**.
  카드마다 노란 「하기」 단추가 붙는다
- 대문(640px 이하) — 같은 카드가 **가로 줄**로 바뀐다. 왼쪽 작은 그림, 오른쪽 「하기」
- 게임 쪽 — 맨 위에 **「게임 목록」으로 돌아가는 알약 단추**(잉크 테두리, 밀린 그림자).
  넓으면 왼쪽에 게임, 오른쪽에 읽을 글. 좁으면 위아래로
- 발 — 옅은 바탕(`#F7F7F7`), 위에 얇은 줄
- 읽는 쪽 (소개·연락·법적) — 한 칸 720px. 흰 벽 그대로,
  오락기 테두리를 쓰지 않는다. 링크만 산호색. `src/styles/text.css`
- 머리 — **왼쪽에 햄버거와 로고, 오른쪽에 나라말 칸.**
  2026-08-23에 햄버거를 오른쪽에서 왼쪽으로 옮겼다. 목차 판도 왼쪽에 붙어 내려온다

## 게임 안쪽 — 여기는 다르다

**캔버스 안의 그림은 안 바꾼다.** 두꺼운 잉크 테두리, 크림색 몸, 눈과 볼이 있는 귀여운
것들이 그대로 있다. **일부러 그렇게 뒀다** — 이 사이트에는 사진이 없고, 게임 그림이
사진 자리를 대신한다. 그림까지 단색으로 만들면 볼 것이 없어진다.

그래서 경계가 이렇다.

| 어디 | 어느 쪽 생김새 |
|---|---|
| 머리·발·읽을 글 | **흰 벽** (이 문서 위쪽) |
| 대문 목록 카드 | **흰 벽 + 오락기 테두리** — 잉크 테두리와 밀린 그림자, 노란 「하기」 단추 |
| 게임 쪽 노는 자리 — 통·HUD·캔버스 테두리·덮개 화면·단추 | **장난감 오락기** |
| `<canvas>` 안에 그리는 것 전부 | **장난감 오락기** |

**2026-08-23에 경계를 한 번 옮겼다.** 처음에는 캔버스 안쪽만 오락기로 뒀는데,
게임 쪽이 너무 밋밋했다. 그래서 **노는 자리를 담는 통까지** 오락기로 되돌렸다.
대문은 안 건드렸다 — 게임이 늘어날수록 목록에 테두리가 많아지면 시끄러워진다.

캔버스 안 규칙은 그대로 —

- 캔버스는 **360×620 고정**. `aspect-ratio` 로 늘린다
- `devicePixelRatio` 는 2로 제한
- 테두리는 잉크색 `#2A3145`, 두껍게 (2.4~4px)
- 적이든 과일이든 **눈과 볼을 그려서** 귀엽게
- `prefers-reduced-motion` 이 켜져 있으면 조각(파티클)을 안 뿌린다
- HUD 는 칸 세 개. **마지막 칸은 늘 「최고」**
- 덮개 화면 셋 — `scReady` / `scOver` / `scPause`. `.on` 클래스로 켜고 끈다
- 손가락용 단추는 `@media (hover:hover)` 에서 숨긴다

## 그림

- 목록 그림은 SVG 로 직접 그린다. 네모(1:1) 안에 꽉 차게. 모서리 12px
- 사진은 쓰지 않는다
- 파비콘은 `public/favicon.svg`
- 대표 그림(`public/og/`)은 `scripts/make-og.mjs` 가 만든다. 손으로 그리지 않는다
