# 새 게임 넣는 차례

게임을 하나 더 넣을 때 **매번 이 차례를 따른다.** 순서를 지키면 빠뜨리는 게 없다.

> 지금은 게임이 `public/` 에 있는 통짜 HTML 이다. **단계 3에서 Astro 부품으로 바꾸면
> 이 문서도 같이 고친다** — 그때는 5번과 6번이 「파일 하나 쓰기」로 줄어든다.

---

## 1. 게임 만들기

`design/README.md` 의 게임 안쪽 규칙을 지킨다. 파일 하나로 끝나야 한다.

- 캔버스 360×620
- HUD 칸 셋, 마지막은 「최고」
- 덮개 화면 셋 — 시작 / 끝 / 멈춤
- 최고 기록은 `window.storage` → 없으면 `localStorage`

## 2. 이름 정하기

- 나라말 여섯 개 다 (`en` `ko` `ja` `es` `fr` `zh`)
- 두 낱말로. 뒷 낱말에 색을 준다
- **일본말·중국말 이름은 짧게.** 길면 제목이 두 줄로 넘어간다
  (겪은 것 — `ぴょんぴょんジャンプ` 는 넘쳐서 `ぴょんジャンプ` 로 줄였다)

## 3. 나라말 여섯 개 넣기

게임 파일 안의 `STR` 사전을 채운다. **캔버스에 그리는 글씨도 빠뜨리지 않는다.**

- HUD 칸 이름은 짧게 — 로마자 8자 안쪽
- 캔버스에 뜨는 글은 한두 낱말
- 숫자가 끼면 `{n}` 자리를 두고 `.replace('{n}', 값)`
- 공통 글(시작·다시 하기·이어 하기·잠깐 멈춤·최고·게임 목록)은
  **다른 게임과 똑같은 말을 쓴다.** 게임마다 다르게 부르지 않는다

## 4. 목록 그림 그리기

66×66 안에 들어가는 SVG. 그 게임의 색으로. 사진은 안 쓴다.

## 5. 파일 넣기

```
public/play/<slug>/index.html
```

`<slug>` 는 영어 이름을 소문자로, 사이는 `-` 로. 보기 — `hoppy-jump`

**넣고 나서 게임 안의 목록 링크를 고친다.**

```js
back.href = '/?lang=' + lang;
```

## 6. `src/data/games.ts` 에 한 줄 넣기

```ts
{
  slug: 'my-game',
  name: { en:'...', ko:'...', ja:'...', es:'...', fr:'...', zh:'...' },
  desc: { en:'...', ko:'...', ja:'...', es:'...', fr:'...', zh:'...' },
  art: `<svg ...>`,
}
```

대문 목록과 사이트맵이 여기서 자동으로 나온다. **다른 곳에 또 적지 않는다.**

## 7. 확인

```bash
npm run build
```

그다음 브라우저로 직접 본다. 자동으로 돌려도 좋다.

- [ ] 나라말 여섯 개를 다 열어봤다
- [ ] 한국말 아닌 쪽에 한글이 안 남았다
- [ ] 글이 칸 밖으로 안 넘친다 (특히 일본말 제목, 프랑스말 설명)
- [ ] 콘솔에 오류가 없다
- [ ] 대문 → 게임 → 대문으로 돌아올 때 언어가 안 바뀐다
- [ ] 게임이 실제로 끝난다 (게임오버가 뜬다)
- [ ] 최고 기록이 남는다
- [ ] 폰 크기(390px 안팎)에서 안 깨진다

## 8. 목록이 길어지면

| 게임 수 | 목록을 어떻게 |
|---|---|
| ~6개 | 지금처럼 한 페이지에 쭉 |
| 7~15개 | 갈래 나누기 — 머리 쓰는 것 / 손이 바쁜 것 / 쌓이는 것 |
| 15개~ | 찾기 칸, 전체 목차 |
