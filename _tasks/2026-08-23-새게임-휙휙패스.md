# 새 게임 — 휙휙 패스 (`long-pass`)

> **뻥뻥 슛을 먼저 끝내고 이걸 한다.** 두 개를 한꺼번에 하지 않는다.
>
> **글은 이미 들어와 있다.** `src/games/long-pass/strings.ts` 에 여섯 나라말이 다 있다.
> **한 글자도 고치지 않는다.**
>
> `design/new-game-checklist.md` 를 옆에 놓고 그 차례를 따른다.

## 목표

미식축구 **패스**. 던지는 건 나고 달리는 건 다른 사람이다.

1. 누르고 있으면 **표적이 앞으로 나간다**
2. 떼면 공이 날아간다. **날아가는 데 시간이 걸린다**
3. 그 사이에도 받는 선수는 계속 달린다 → **갈 자리로 던져야 한다**

기회 네 번으로 100야드를 간다. 끝 선을 넘으면 네 번을 다시 받는다.

**왜 이 게임인가** — 뻥뻥 슛과 **일부러 다르게** 잡았다.
승부차기는 「막는 놈을 피하기」, 이건 「움직이는 것을 예측하기」다.
손가락은 똑같이 쓰는데 머릿속에서 하는 일이 다르다.
겨냥해서 목표를 맞히는 게임을 두 개 만들면 그림만 다른 같은 게임이 된다.

## 3. 화면 짜임 — 캔버스 360×620

**화면은 안 움직인다.** 늘 앞쪽 50야드만 보인다.

| 무엇 | 자리 |
|---|---|
| 잔디 | 전체 `#7FD8C8` |
| 야드 선 | `y 540` 부터 위로 47px 마다 (=5야드), 크림색 `#FFF7EA`, 굵기 2, 투명도 0.7 |
| 스크리미지 선 | `y 540`, 크림색 굵기 4 |
| 던지는 사람 | `(180, 572)` 산호색 `#FF385C` 옷 |
| 받는 선수 | 산호색 `#FF385C` 옷. 지름 20쯤 |
| 수비 | 남색 `#3B4CCA` 옷 |
| 끝 선 | 남은 거리가 50야드 아래로 내려오면 보인다. 굵은 산호색 줄 |
| 표적 | 누르고 있는 동안 보이는 고리. 산호색 |

**1야드 = 9.4px.** 화면 위쪽 `y 70` 이 50야드 앞이다.

끝 선 자리 = `540 - toGo * 9.4`. `toGo` 가 50보다 크면 화면 밖이라 안 그린다.
그럴 때는 화면 위쪽에 `T.toGo.replace('{n}', toGo)` 를 작게 띄운다.

## 4. 노는 차례 (상태)

```
ready → aim → fly → result → (aim | over)
                       ↑
                    paused (P)
```

| 상태 | 무엇 |
|---|---|
| `ready` | `scReady` 덮개. 「시작」 → `aim` |
| `aim` | 받는 선수와 수비가 달린다. 아래에 `T.readyHint` |
| `aim` (누르는 중) | 표적이 앞으로 나간다. 아래에 `T.holdHint` |
| `fly` | 떼면 공이 날아간다. 선수들은 **계속 달린다** |
| `result` | `T.caught` / `T.incomplete` / `T.picked` / `T.touchdown` 을 1초 |
| `over` | `scOver` 덮개 |

**중요 — 누르지 않아도 선수들은 달리고 있다.** 표적만 누를 때 나간다.
너무 오래 기다리면 받는 선수가 화면 밖으로 나가므로, 화면 위 `y 60` 에 닿으면
그 차례는 **놓친 것**으로 치고 기회가 하나 준다.

**누르는 것 세 가지가 다 같다** — 캔버스 누르기, `스페이스`, `엔터`.
누른 채로 있다가 떼면 던진다. 키보드는 **누르고 있는 동안**(`keydown` 반복 무시) 표적이 나가고
`keyup` 에 던진다.

## 5. 숫자 — 그대로 쓴다

`tds` 는 이번 판에서 넘은 끝 선 수다.

```js
const PXY        = 9.4;                              // 1야드 = 9.4px
const LOS        = 540;                              // 스크리미지 선
const MARK_SPEED = 235;                              // 표적이 나가는 속도 px/초
const MARK_MAX   = 470;                              // 최대 50야드
const RECV_SPEED = Math.min(200, 118 + tds * 14);    // 받는 선수 px/초
const FLY_BASE   = 0.18;                             // 공이 나는 기본 시간(초)
const FLY_PER_PX = 0.0020;                           // 거리 1px 당 더해지는 시간
const CATCH_R    = 34;                               // 잡는 반지름
const PICK_R     = 30;                               // 가로채는 반지름
const DEFS       = Math.min(3, 1 + tds);             // 수비 수
const DOWNS      = 4;
```

**공이 나는 시간** = `FLY_BASE + 거리 * FLY_PER_PX`.
40야드(376px)면 `0.18 + 0.75 = 0.93초`. 그 사이 받는 선수는 110px(약 12야드)를 간다.
**「그만큼 앞을 봐야 한다」가 여기서 나온다.** 숫자를 바꾸지 않는다.

### 받는 선수가 뛰는 길

`LOS` 에서 `x = 180 + (무작위 -70 ~ +70)` 으로 시작해서 위로 달린다.
좌우로 흔들린다 — `x += Math.sin(t * 3.9) * 40 * dt` 쯤. 곧게만 가면 너무 쉽다.

### 수비

`i` 번째 수비는 `y = LOS - 120 - i * 90`, `x` 는 무작위.

- 위로 `RECV_SPEED * 0.85` 로 간다
- 받는 선수 쪽으로 옆으로 `RECV_SPEED * 0.55` 로 붙는다

## 6. 판정 — 공이 떨어질 때 한 번만

```js
const dRecv = 거리(land, 받는선수);
let   dDef  = 수비들 중 land 에서 제일 가까운 거리;

if (dDef < PICK_R && dDef < dRecv)  → 가로채기 (T.picked),  기회 -2
else if (dRecv < CATCH_R)           → 잡음     (T.caught),  기회 -1
else                                → 놓침     (T.incomplete), 기회 -1
```

**차례가 중요하다.** 가로채기를 먼저 본다.

### 잡았으면

```js
const yards = Math.round((LOS - land.y) / PXY);
score += yards;
toGo  -= yards;
if (toGo <= 0) {                      // 끝 선을 넘었다
  → T.touchdown, score += 25, tds += 1, toGo = 100, 기회 = DOWNS
}
```

잡은 자리에 `T.gain.replace('{n}', yards)` 를 띄운다.

기회가 0 이하가 되면 `over`.

## 8. 그림에서 챙길 것

- 선수는 다른 게임과 같은 규칙 — 잉크 테두리 `#2A3145`, 눈 두 개
- **받는 선수는 산호색, 수비는 남색.** 한눈에 갈려야 한다
- 공은 갈색 타원(`#C87A4B`)에 크림색 실밥 한 줄. 날아가는 동안 빙글 돈다
- 표적은 산호색 고리. 누르고 있는 동안만 보인다
- 공이 나는 동안 그림자를 땅에 그리면 어디 떨어질지 읽기 쉽다
- `prefers-reduced-motion` 이 켜져 있으면 조각과 흔들기를 안 한다

## 하지 말 것

- **`strings.ts` 를 고치지 않는다.** 이상하면 알려 달라
- 5번·6번 숫자를 바꾸지 않는다. 「잘하는 요령」이 거짓말이 된다
- 화면을 위아래로 굴리지 않는다 (카메라 고정)
- 진짜 팀·선수·리그 이름이나 무늬를 쓰지 않는다
- 바깥 CSS 를 새로 쓰지 않는다. `game.css` 에 다 있다
- 게임 안에 `LANGS` `pickLang()` `apply()` 를 만들지 않는다
- 게임 코드 안에 `T` 라는 이름의 다른 변수를 두지 않는다
- `<style>` 과 `<script>` 는 **`</GameLayout>` 안쪽 맨 끝**에 둔다

---

## 끝났다는 신호

- 여섯 주소가 다 열린다
- 누르고 있으면 표적이 앞으로 나가고, 떼면 공이 날아간다
- **선수 있는 자리로 던지면 대부분 놓친다. 앞으로 던져야 잡는다**
- 멀리 던질수록 더 많이 앞을 봐야 한다
- 수비 옆에 떨어뜨리면 가로채이고 기회가 **둘** 준다
- 100야드를 넘으면 터치다운이 뜨고 기회가 넷으로 돌아온다
- 기회를 다 쓰면 끝 화면이 뜬다
