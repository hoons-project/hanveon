# 새 게임 — 톡톡 정리 (`tidy-tubes`)

> **글은 이미 들어와 있다.** `src/games/tidy-tubes/strings.ts` 에 여섯 나라말이 다 있다.
> **한 글자도 고치지 않는다.**
>
> `design/new-game-checklist.md` 를 옆에 놓고 그 차례를 따른다.

## 목표

색 알을 병에 정리하는 **머리 쓰는 게임.** 시간 제한도 쫓아오는 것도 없다.

- 병을 누르면 맨 위 알이 들린다. 다른 병을 누르면 거기에 놓인다
- 알은 **같은 색 위**나 **빈 병**에만 놓인다
- 한 색으로 네 개를 채우면 그 병은 끝. 병을 다 정리하면 다음 단계
- **되돌리기는 한 판 내내 다섯 번**. 단계가 넘어가도 안 채워진다
- 옮길 데가 없고 되돌리기도 없으면 끝

## 왜 이 게임인가

지금 여덟 개 중 **여섯 개가 순발력 게임**이다. 손이 느리거나, 반응 속도로 겨루기
싫거나, 조용히 하고 싶은 사람이 고를 게 쭉쭉 구슬 하나뿐이다.

이건 **손을 전혀 안 바쁘게 하는 첫 게임**이다. 누르기만 하고, 시간이 안 간다.
잘못 눌러서 죽는 일이 없다. 지금 사이트에 그런 자리가 비어 있다.

## 4. 규칙 — 정확히 이대로

```js
const CAP = 4;                                   // 병 하나에 알 네 개
function colors(level){ return Math.min(8, 3 + level); }   // 1단계 4색 … 5단계 8색
function empties(level){ return level <= 5 ? 2 : 1; }      // 6단계부터 빈 병 하나
function tubes(level){ return colors(level) + empties(level); }
const UNDOS = 5;                                 // 한 판 내내. 단계가 넘어가도 안 채운다
```

**놓을 수 있는 조건** — `from` 의 맨 위 알을 `to` 로 옮길 수 있는가

```js
function canMove(from, to){
  if (from === to) return false;
  if (from.length === 0) return false;
  if (to.length >= CAP) return false;
  if (to.length === 0) return true;
  return to[to.length - 1] === from[from.length - 1];
}
```

**한 판을 깼는가** — 모든 병이 비었거나, 같은 색으로 `CAP` 만큼 찼는가

**막혔는가** — 어떤 `from`·`to` 짝에도 `canMove` 가 참이 아닌가

**끝** — 막혔는데 되돌리기가 0이면 `over`.
막혔지만 되돌리기가 남아 있으면 `T.stuck` 을 띄우고 되돌리기를 기다린다.

## 5. 섞기 — **여기가 제일 중요하다**

**아무렇게나 섞으면 안 된다.** 못 푸는 판이 나올 수 있고, 1단계에서 그러면 최악이다.

**다 맞춰 놓은 상태에서 거꾸로 옮겨 가며 섞는다.** 그러면 **반드시 풀린다** —
섞은 차례를 거꾸로 되짚는 것이 곧 답이기 때문이다.

```js
function deal(level){
  const nC = colors(level), nT = tubes(level);
  /* 다 맞춰 놓은 상태 */
  const t = [];
  for (let c = 0; c < nC; c++) t.push([c, c, c, c]);
  for (let e = nC; e < nT; e++) t.push([]);

  /* 거꾸로 옮기기 */
  const STEPS = nC * 40;
  for (let s = 0; s < STEPS; s++) {
    /* 알을 뺄 병 B — 비어 있지 않은 것 */
    const from = pickRandom(t.filter(x => x.length > 0));
    const ball = from[from.length - 1];
    /* 뺀 뒤에 B 가 비거나, B 의 새 맨 위가 같은 색이어야 한다.
       그래야 거꾸로 되짚을 때 canMove 가 참이 된다 */
    const rest = from.length - 1;
    const ok = rest === 0 || from[rest - 1] === ball;
    if (!ok) continue;
    /* 놓을 병 A — 가득 차지 않은 다른 병 */
    const cand = t.filter(x => x !== from && x.length < CAP);
    if (!cand.length) continue;
    const to = pickRandom(cand);
    to.push(from.pop());
  }
  return t;
}
```

**왜 저 `ok` 조건이 필요한가** — 거꾸로 옮긴 것을 되짚으려면
「A 의 맨 위를 B 로 옮기기」가 `canMove` 를 통과해야 한다. B 에서 알을 뺀 뒤
B 가 비었거나 B 의 맨 위가 그 알과 같은 색일 때만 통과한다. 그 조건이다.

**섞고 나서 이미 다 맞춰진 판이 나오면 다시 섞는다** (`STEPS` 가 적을 때 드물게 난다).

## 6. 조작

| 어떻게 | 무엇 |
|---|---|
| 병을 누르기 | 아무것도 안 들었으면 그 병의 맨 위 알을 든다 |
| 다른 병을 누르기 | `canMove` 면 놓는다. 아니면 **아무 일도 안 일어난다** (흔들어서 알려 준다) |
| 든 병을 다시 누르기 | 내려놓는다 (취소) |
| `←` `→` | 병 고르기 |
| `스페이스` · `엔터` | 들기 / 놓기 |
| `Z` | 되돌리기 |
| `P` | 멈춤 |

**되돌리기는 옮긴 것 하나를 되돌린다.** 단계가 넘어가면 되돌리기 기록은 비운다
(앞 단계로는 못 돌아간다). **남은 횟수는 안 채운다.**

## 8. 그림에서 챙길 것

- 알에 **눈 두 개**를 그린다. 다른 게임과 같은 규칙이다
- 든 알은 살짝 위아래로 흔들리게 (`prefers-reduced-motion` 이면 안 흔든다)
- 놓을 수 없는 병을 누르면 그 병을 좌우로 짧게 흔든다
- 다 채운 병은 테두리를 굵게 하고 위에 작은 표시를 준다
- 조각(파티클)은 한 판을 깼을 때만

## 하지 말 것

- **`strings.ts` 를 고치지 않는다.** 이상하면 알려 달라
- 4·5번 숫자와 규칙을 바꾸지 않는다. 「잘하는 요령」 세 줄이 거기서 나온다
- **아무렇게나 섞지 않는다.** 5번 방식만 쓴다
- 시간 제한을 넣지 않는다. 이 게임의 요점이다
- 바깥 CSS 를 새로 쓰지 않는다
- 게임 안에 `LANGS` `pickLang()` `apply()` 를 만들지 않는다
- 게임 코드 안에 `T` 라는 이름의 다른 변수를 두지 않는다
- `<style>` 과 `<script>` 는 **`</GameLayout>` 안쪽 맨 끝**에 둔다

---

## 끝났다는 신호

- 여섯 주소가 다 열린다
- 병을 누르면 알이 들리고, 다른 병을 누르면 놓인다
- **못 놓는 자리에는 안 놓인다**
- 병을 다 정리하면 다음 단계로 가고 색이 하나 는다
- 6단계에서 빈 병이 하나로 준다
- 되돌리기가 다섯에서 줄고, 단계가 넘어가도 안 채워진다
- 막혔는데 되돌리기가 0이면 끝 화면
