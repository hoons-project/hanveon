# 「비슷한 게임」이 앞쪽 게임으로만 몰리는 것 고치기

## 목표

`related()` 가 **늘 목록 앞쪽부터** 두 개를 집는다. 그래서 받는 링크가 이렇게 쏠린다.

| 게임 | 받는 링크 |
|---|---|
| 폴짝 점프 · 붕붕 드라이브 | 5개씩 |
| 슝슝 비행기 | 2개 |
| 몽글 과일 · 탕탕 사격 · 쭉쭉 구슬 | **0개** |

세 게임이 아무 데서도 링크를 못 받는다. 「게임 쪽끼리 이어져서 검색에 도움이 된다」는
원래 뜻이 절반만 이뤄진 셈이다.

**이건 앞 지시서를 쓴 쪽의 잘못이다.** `slice(0, 2)` 가 늘 앞에서 집는다는 걸 못 봤다.
클로드 코드는 시킨 대로 넣고 결함을 찾아냈다 — 맞게 한 것이다.

고치는 법 — **같은 갈래 하나 + 자기 다음 차례부터 둥글게 하나.** 무작위는 여전히 안 쓴다.

## 1. `src/data/games.ts`

지금 `related()` 를 통째로 아래로 갈아 끼운다.

```ts
/**
 * 「비슷한 게임」 고르기.
 *
 * 두 가지를 같이 만족시켜야 한다 —
 *   1. 되도록 같은 갈래를 보여준다
 *   2. **모든 게임이 링크를 받는다.** 앞쪽 게임만 뽑히면 안 된다
 *
 * 그래서 자기 **다음 차례부터 둥글게** 돌면서 고른다.
 * 첫 칸은 같은 갈래, 남은 칸은 둥글게 다음 것으로 채운다.
 * 무작위를 쓰지 않는다 — 빌드할 때마다 같은 것이 나와야 한다.
 */
export function related(g: Game, n = 2): Game[] {
  const i = GAMES.findIndex((x) => x.slug === g.slug);
  /* 자기 다음부터 둥글게. 자기 자신은 안 들어간다 */
  const rot = [...GAMES.slice(i + 1), ...GAMES.slice(0, i)];

  const picked: Game[] = [];

  /* 첫 칸 — 같은 갈래 중 둥글게 첫 번째. 같은 갈래가 없으면 건너뛴다 */
  const same = rot.find((x) => x.kind === g.kind);
  if (same) picked.push(same);

  /* 남은 칸 — 둥글게 돌면서 아직 안 고른 것으로 채운다 */
  for (const x of rot) {
    if (picked.length >= n) break;
    if (!picked.includes(x)) picked.push(x);
  }

  return picked.slice(0, n);
}
```

### 이렇게 되면 이렇게 나온다 (게임 여섯 개일 때)

| 게임 | 보내는 링크 |
|---|---|
| 폴짝 점프 | 붕붕 드라이브 · 몽글 과일 |
| 붕붕 드라이브 | 슝슝 비행기 · 몽글 과일 |
| 몽글 과일 | 슝슝 비행기 · 탕탕 사격 |
| 슝슝 비행기 | 탕탕 사격 · 쭉쭉 구슬 |
| 탕탕 사격 | 폴짝 점프 · 쭉쭉 구슬 |
| 쭉쭉 구슬 | 폴짝 점프 · 붕붕 드라이브 |

**받는 링크가 여섯 게임 모두 정확히 2개**가 된다.

> 다만 **이건 지금 여섯 개일 때의 셈이다.** 게임이 늘거나 갈래가 바뀌면 다시 세어 봐야
> 한다. 그래서 아래 확인 차례에 「세어 본다」를 넣었다. 표를 믿지 말고 직접 센다.

## 하지 말 것

- `related()` 말고 다른 것을 고치지 않는다 — 마크업·CSS·`kind` 값·글 전부 그대로
- 무작위(`Math.random`)를 쓰지 않는다. 빌드할 때마다 같아야 한다
- 대문·햄버거 목차를 건드리지 않는다
- 갈래를 다시 나누지 않는다. 지금 `kind` 값 그대로 둔다
- 대표 그림은 그대로

---

## 끝났다는 신호

게임 여섯 개를 다 열었을 때 —

- 「비슷한 게임」이 늘 두 장
- **여섯 게임이 모두 어딘가에서 링크를 받는다.** 0개짜리가 없다
- 몽글 과일·탕탕 사격·쭉쭉 구슬이 다른 게임 쪽에 나타난다

## 확인 차례

```bash
npm run build
```

**받는 링크를 직접 센다.** 빌드한 뒤 아래를 그대로 돌리면 된다.

```bash
node -e '
const fs=require("fs");
const S=["hoppy-jump","zoom-drive","merge-fruit","zippy-plane","pop-shot","chain-dots"];
const inn={}; S.forEach(s=>inn[s]=0);
for (const s of S){
  const h=fs.readFileSync(`dist/play/${s}/index.html`,"utf8");
  const m=[...h.matchAll(/class="relcard" href="\/play\/([a-z-]+)\//g)].map(x=>x[1]);
  console.log(s,"→",m.join(" · "));
  m.forEach(t=>inn[t]++);
}
console.log("받는 링크:",inn);
'
```

- [ ] 위 셈에서 **0인 게임이 하나도 없다**
- [ ] 자기 자신이 안 나온다
- [ ] 빌드를 두 번 돌려 결과가 같다 (무작위가 안 섞였는지)
- [ ] 나라말 여섯 개에서 링크가 그 나라말 앞자리를 단다
- [ ] 폰 크기(390px)에서 두 장이 위아래로 쌓인다
- [ ] 콘솔에 오류가 없다
