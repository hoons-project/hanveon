# `_tasks/` — 클로드 코드에 넘기는 작업 지시서

2026-08-23에 정한 것. 이 프로젝트는 둘이 나눠서 한다.

| 누가 | 무엇 |
|---|---|
| **클로드 코드** (맥북, 이 저장소 안) | 코드를 쓰고 고친다. 빌드·커밋·푸시 |
| **클로드 (Cowork, 클라우드)** | 정하기 · 조사 · 여섯 나라말 글 · 브라우저 확인 · 노션 기록 · **이 지시서 쓰기** |

## 쓰는 법

Cowork 쪽이 여기에 파일을 하나 넣는다. 이름은 이렇게.

```
_tasks/2026-08-23-게임쪽-읽을글.md
```

훈쓰는 맥북 터미널에서 저장소로 가서 클로드 코드에 한 줄만 치면 된다.

```
_tasks/2026-08-23-게임쪽-읽을글.md 읽고 그대로 해줘
```

## 지시서에 꼭 들어가는 것

1. **목표** — 한두 줄. 무엇이 달라지면 되는지
2. **손댈 파일** — 정확한 경로. 새로 만들 것과 고칠 것을 나눠서
3. **하지 말 것** — 건드리면 안 되는 파일과 규칙
4. **끝났다는 신호** — 눈으로 확인할 수 있는 것
5. **확인 차례** — `npm run build` 부터 브라우저로 볼 것까지

## 끝난 지시서

지운다. `git log` 에 남으니 따로 보관하지 않는다.
다만 **왜 그렇게 정했는지**는 지시서가 아니라 `CLAUDE.md` 나 `design/` 에 적는다.
지시서는 시키는 글이고, 그 두 곳은 기준이다.
