# 대문의 겹치는 한 줄 빼고, 게임 쪽 「게임 목록」 단추 눈에 띄게

## 목표

두 가지, 서로 상관없는 작은 고침이다.

**1. 「게임은 계속 늘어나요」가 대문에 두 번 나온다.**
위쪽 설명 줄(`.lede`)에 이미 들어 있는데 목록 아래(`.more`)에 또 있다.
**아래쪽을 지운다.** 여섯 나라말 모두 위쪽 설명에 같은 뜻이 들어 있어서 잃는 것이 없다.

| 나라말 | 위쪽 설명(`metaDesc`)에 이미 있는 부분 |
|---|---|
| en | `New games added regularly.` |
| ko | `게임은 계속 늘어나요.` |
| ja | `ゲームは少しずつ増えていきます。` |
| es | `Añadimos juegos nuevos cada poco.` |
| fr | `De nouveaux jeux arrivent régulièrement.` |
| zh | `新游戏会不断加入。` |

**2. 게임 쪽 맨 위 「게임 목록」이 눈에 안 띈다.**
지금은 작은 흐린 글씨다. **알약 단추로 바꾼다** — 흰 바탕에 잉크 테두리, 밀린 그림자,
누르면 내려간다. 대문 카드와 같은 말투다.

---

## 손댈 파일

1. `src/components/Hub.astro` — 한 줄 지우기
2. `src/styles/global.css` — `.more` 규칙 지우기
3. `src/i18n/ui.ts` — `more` 글 지우기 (쓰는 데가 없어진다)
4. `src/styles/game.css` — `.crumb` 를 알약 단추로
5. `design/README.md` — 「짜임」 칸에 한 줄

---

## 1. `src/components/Hub.astro`

`.cards` 를 닫는 `</div>` 아래의 이 줄을 **지운다.**

```astro
  <p class="more">{t.more}</p>
```

빈 줄도 같이 정리한다. 다른 것은 안 건드린다.

---

## 2. `src/styles/global.css`

이 덩어리를 **통째로 지운다.**

```css
/* 「게임은 계속 늘어나요」 — 목록 아래 조용한 한 줄 */
.more{
  margin-top:32px;
  display:inline-flex;align-items:center;gap:8px;
  font-size:14px;font-weight:500;color:var(--hof);
  background:var(--faint);
  border-radius:9999px;
  padding:9px 16px;
}
```

---

## 3. `src/i18n/ui.ts`

**`more` 를 쓰는 데가 없어지므로 지운다.** 안 쓰는 자료를 남겨 두지 않는다.

- `UiKey` 에서 이 줄을 지운다 — `  | 'more'         // 게임이 계속 늘어난다는 한 줄`
- 여섯 나라말 덩어리에서 `more: '…',` 줄을 각각 지운다 (여섯 줄)

**`metaDesc` 는 절대 건드리지 않는다.** 위쪽 설명 줄이 그걸 쓰고, 검색 결과에도 나간다.

---

## 4. `src/styles/game.css`

지금 `.crumb` 덩어리 두 줄을 아래로 갈아 끼운다.

```css
/* 지금 있는 것 — 지운다
.crumb{
  margin-bottom:10px;
  font-size:14px;color:var(--foggy);
}
.crumb a:hover{color:var(--hof)}
*/
```

새로 넣을 것 —

```css
/* 게임 목록으로 돌아가는 단추.
   전에는 작은 흐린 글씨라 눈에 안 띄었다. 대문 카드와 같은 알약 단추로 만든다. */
.crumb{ margin-bottom:14px }
.crumb a{
  display:inline-flex;align-items:center;
  background:var(--white);color:var(--ink);
  border:2px solid var(--ink);
  border-radius:9999px;
  box-shadow:0 3px 0 var(--ink);
  padding:8px 16px;
  font-size:13.5px;font-weight:800;letter-spacing:-0.01em;
  transition:transform .07s, box-shadow .07s;
}
.crumb a:active{ transform:translateY(3px); box-shadow:0 0 0 var(--ink) }
@media (hover:hover){
  .crumb a:hover{ background:var(--faint) }
}
```

마크업(`GameLayout.astro` 의 `<p class="crumb"><a …>‹ {t.allGames}</a></p>`)은 **그대로 둔다.**

## 5. `design/README.md`

「짜임」 칸의 게임 쪽 줄을 아래로 바꾼다.

```
- 게임 쪽 — 맨 위에 **「게임 목록」으로 돌아가는 알약 단추**(잉크 테두리, 밀린 그림자).
  넓으면 왼쪽에 게임, 오른쪽에 읽을 글. 좁으면 위아래로
```

---

## 하지 말 것

- **`metaDesc` 를 건드리지 않는다.** 위쪽 설명 줄과 검색 결과에 쓰인다
- `t.allGames` 를 건드리지 않는다. 햄버거 목차의 머리말에도 쓰인다
- 대문 카드(`.cards` `.gcard` `.go`)를 건드리지 않는다
- 게임 노는 자리(`.play` `.hud` `canvas` `.card`)를 건드리지 않는다
- 게임 자바스크립트를 건드리지 않는다
- 대표 그림은 그대로. `scripts/make-og.mjs` 는 `metaDesc` 와 `freeTag` 만 쓰므로 안 바뀐다

---

## 끝났다는 신호

- `/ko/` 에서 「게임은 계속 늘어나요」가 **위쪽 설명 줄에 한 번만** 나온다. 목록 아래에는 없다
- `/ko/play/hoppy-jump/` 맨 위의 「‹ 게임 목록」이
  **테두리와 그림자가 있는 알약 단추**로 보이고, 누르면 아래로 내려간다
- 나라말 여섯 개 다 마찬가지
