# 새 게임 — 뻥뻥 슛 (`spot-kick`)

> **글은 이미 들어와 있다.** `src/games/spot-kick/strings.ts` 를 열어 보면
> 여섯 나라말 글이 그대로 있다. **한 글자도 고치지 않는다.**
> 이 지시서는 **게임을 만드는 일**을 시킨다.
>
> `design/new-game-checklist.md` 를 옆에 놓고 그 차례를 따른다. 여기 있는 것은
> 그 차례의 **1·3·5번**을 이 게임에 맞게 구체적으로 적은 것이다.

## 목표

끝나지 않는 **승부차기**. 두 번 누르면 한 번 찬다.

1. 겨냥 표시가 골대 앞을 좌우로 왔다 갔다 한다 → 누르면 **방향**이 정해진다
2. 힘 막대가 오르내린다 → 누르면 **힘**이 정해진다
3. 공이 날아가고 골키퍼가 몸을 날린다. 골이거나, 막히거나, 골대를 넘는다

세 번 못 넣으면 끝. 최고 기록은 **넣은 골 수**.

**왜 이 게임인가** — 지금 여섯 게임이 다 「계속 움직이는 것」이다.
이건 **한 번에 한 번씩 끊어서** 하는 게임이라 결이 다르다. 버스에서 한 손으로 된다.

## 5. 노는 차례 (상태)

```
ready → aim → power → fly → result → (aim | over)
                                ↑
                             paused (P)
```

| 상태 | 무엇 | 넘어가는 것 |
|---|---|---|
| `ready` | `scReady` 덮개 | 「시작」 단추 → `aim` |
| `aim` | 겨냥 표시가 좌우로. 아래에 `T.aimHint` | 누르면 `aimX` 확정 → `power` |
| `power` | 힘 막대가 오르내림. 아래에 `T.powerHint` | 누르면 `p` 확정 → `fly` |
| `fly` | 0.55초 동안 공이 날고 골키퍼가 몸을 날림 | 끝나면 판정 → `result` |
| `result` | `T.scored` / `T.saved` / `T.over` 를 크게 0.9초 | 기회가 남으면 `aim`, 없으면 `over` |
| `over` | `scOver` 덮개 | 「다시 하기」 → `ready` 값으로 되돌리고 `aim` |

**누르는 것은 세 가지가 다 같다** — 캔버스를 손가락·마우스로 누르기, `스페이스`, `엔터`.
`P` 는 멈춤. `scPause` 를 쓴다.

`result` 동안 누르면 **아무 일도 안 일어난다.** 연달아 눌러서 건너뛰지 못하게 한다.

## 6. 숫자 — 그대로 쓴다

`goals` 는 이번 판에서 넣은 골 수다.

```js
const FLY        = 0.55;                                  // 공이 나는 시간(초)
const AIM_SPEED  = Math.min(430, 190 + goals * 11);       // 겨냥 표시 px/초
const PWR_RATE   = Math.min(2.2, 0.85 + goals * 0.05);    // 힘 막대 왕복/초
const LIVES      = 3;
```

**겨냥 표시** — `x 62 ↔ 298` 사이를 왔다 갔다. 끝에 닿으면 방향을 뒤집는다.

**힘 막대** — `p` 가 `0 → 1 → 0` 을 되풀이한다. `PWR_RATE` 가 초당 왕복 횟수.
막대에 색 띠를 그려서 어디가 어디인지 보이게 한다.

| `p` | 색 | 무엇 |
|---|---|---|
| `0 – 0.28` | 회색 `#B0B0B0` | 약하다 — 골키퍼가 여유 있게 잡는다 |
| `0.28 – 0.92` | 노랑 `#FFD23F` → 산호 `#FF385C` 로 이어지게 | 쓸 만하다 |
| `0.92 – 1` | 빨강 `#E23` | 골대를 넘긴다 |

**공이 닿는 자리**

```js
const targetY = 214 - p * 118;      // p=0 → 214(땅) · p=1 → 96(크로스바 높이)
const targetX = aimX;
```

**공 그리기** — `(180, 500)` 에서 `(targetX, targetY)` 로. 반지름은 `13 → 8` 로 줄인다
(멀어지니까). 살짝 뜨게 `y -= Math.sin(t / FLY * Math.PI) * 18` 을 더한다.

## 7. 골키퍼 — **여기가 이 게임의 알맹이다**

「잘하는 요령」 세 줄이 **실제로 맞아야 한다.** 아래대로 만들면 맞는다.

### 7-1. 어디로 뛰는지 고르기 (공을 차는 순간 정한다)

세 자리 — 왼쪽 `96` · 가운데 `180` · 오른쪽 `264`. 고른 자리에 `±18` 만큼 흔든다.

```js
// 앞선 두 번을 기억한다. -1 왼쪽 · 0 가운데 · +1 오른쪽
// side(x) = x < 140 ? -1 : x > 220 ? 1 : 0
const BIAS = Math.min(0.62, 0.28 + goals * 0.02);

let zone;
if (hist.length === 2 && hist[0] === hist[1] && Math.random() < BIAS) {
  zone = hist[0];                 // 같은 쪽으로 두 번 찼으면 그쪽으로 기운다
} else {
  zone = [-1, 0, 1][Math.floor(Math.random() * 3)];
}
```

**이것이 「방향을 바꿔 가며 차라」는 요령을 참으로 만든다.**
같은 구석만 계속 노리면 갈수록 막힌다.

`hist` 는 **찬 뒤에** 밀어 넣는다. 길이는 2로 유지한다.

### 7-2. 언제 뛰는지

`t = 0.14초` 에 출발해서 `t = 0.44초` 에 도착. 그 사이를 부드럽게 이어 준다
(`easeOutCubic` 쯤). 몸을 옆으로 눕혀서 그린다 — 뛰는 쪽으로 기운다.

### 7-3. 판정 — `t = FLY` 일 때 한 번만

**차례가 중요하다. 위에서부터 본다.**

```js
if (p > 0.92)            → 넘어감  (T.over)
else {
  let reach = 46 + Math.min(14, goals * 0.6);   // 갈수록 조금씩 넓어진다
  if (p < 0.28)      reach *= 2;                 // 약하게 차면 여유가 생긴다
  if (targetY < 132) reach *= 0.52;              // 위쪽 구석은 손이 잘 안 닿는다
  if (Math.abs(ballX - keeperX) < reach) → 막힘 (T.saved)
  else                                   → 골   (T.scored)
}
```

`reach` 세 줄이 「잘하는 요령」 세 줄과 **하나씩 짝이 맞는다.** 숫자를 바꾸지 않는다.

### 7-4. 골이면

`goals + 1`, `streak + 1`. `streak` 이 3 이상이면 캔버스 위쪽에
`T.streak.replace('{n}', streak)` 를 작게 띄운다.

못 넣으면 `streak = 0`, `lives - 1`. `lives` 가 0 이면 `over`.

## 9. 그림에서 챙길 것

- **골키퍼는 귀엽게.** 눈 두 개, 볼. 유니폼은 `#FFD23F`, 테두리 `#2A3145`
- 공은 크림색 `#FFF7EA` 에 잉크 테두리, 가운데 오각형 하나
- 겨냥 표시는 산호색 `#FF385C` 화살표나 고리. 골라인 위에 놓는다
- 골이면 그물이 잠깐 출렁이게 (그물 선을 몇 프레임 밀어 준다)
- `prefers-reduced-motion` 이 켜져 있으면 **조각(파티클)과 흔들기를 안 한다**

## 하지 말 것

- **`strings.ts` 를 고치지 않는다.** 이상하면 알려 달라
- 위 7번 숫자를 바꾸지 않는다. 「잘하는 요령」이 거짓말이 된다
- 진짜 팀·선수·리그 이름이나 무늬를 쓰지 않는다
- 바깥 CSS 를 새로 쓰지 않는다. `game.css` 에 다 있다 —
  `.hud` `.stage` `canvas` `.screen` `.card` `.legend` `.chip` `button` `.help` `.guide`
- 게임 안에 `LANGS` `pickLang()` `apply()` 를 만들지 않는다
- 게임 코드 안에 `T` 라는 이름의 다른 변수를 두지 않는다
- `<style>` 과 `<script>` 는 **`</GameLayout>` 안쪽 맨 끝**에 둔다.
  밖에 두면 `<body>` 밖으로 나간다
- 대문·읽는 쪽·다른 게임을 건드리지 않는다

## 끝났다는 신호

- `/play/spot-kick/` 과 `/ko/play/spot-kick/` … 여섯 주소가 다 열린다
- 두 번 누르면 공이 날아가고, 골이거나 막히거나 넘어간다
- 같은 구석만 계속 노리면 **눈에 띄게 더 막힌다**
- 위쪽 구석에 세게 차면 잘 들어가고, 더 세게 차면 넘어간다
- 세 번 못 넣으면 끝 화면이 뜬다. 다시 하면 처음부터
- 최고 기록이 남는다
