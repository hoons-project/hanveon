# 게임에 갈래 붙이고, 게임 쪽에 「비슷한 게임」 넣기

> **앞 지시서 둘을 먼저 끝내고 이걸 한다.**

## 목표

게임마다 **갈래**를 자료에 적어 둔다. **대문은 아직 나누지 않는다** — 지금 여섯 개를
나누면 4 : 1 : 1 이라 갈래 둘이 한 개짜리가 되어 오히려 휑하다. 게임이 열 개쯤 되면
그때 대문을 나눈다.

대신 갈래를 **지금 바로 쓸 데**가 하나 있다. 게임 쪽 맨 아래에 **「비슷한 게임」 둘**을
보여준다. 노는 사람이 다음 게임으로 바로 넘어가고, 게임 쪽끼리 링크가 이어져서
검색에도 도움이 된다.

## 1. `src/data/games.ts`

### 1-1. 갈래 종류

`const SPACED` 줄 **뒤에** 넣는다.

```ts
/** 게임 갈래. 대문을 나누는 데는 아직 안 쓰고, 「비슷한 게임」 고르는 데 쓴다. */
export type Kind = 'quick' | 'think' | 'stack';
```

### 1-2. `Game` 자료에 한 칸

`slug` 아래에 넣는다.

```ts
  /** 갈래. 지금은 「비슷한 게임」 고르는 데만 쓴다. */
  kind: Kind;
```

### 1-3. 게임마다 갈래 적기

각 게임의 `slug` 줄 바로 아래에 넣는다.

| slug | 넣을 줄 |
|---|---|
| `hoppy-jump` | `kind: 'quick',` |
| `zoom-drive` | `kind: 'quick',` |
| `merge-fruit` | `kind: 'stack',` |
| `zippy-plane` | `kind: 'quick',` |
| `pop-shot` | `kind: 'quick',` |
| `chain-dots` | `kind: 'think',` |

### 1-4. 비슷한 게임 고르는 함수

`findGame` 아래에 넣는다.

```ts
/**
 * 「비슷한 게임」 고르기.
 * 같은 갈래를 먼저 담고, 모자라면 다른 갈래에서 채워서 **늘 n 개**를 준다.
 * 무작위를 쓰지 않는다 — 빌드할 때마다 같은 것이 나와야 한다.
 */
export function related(g: Game, n = 2): Game[] {
  const same = GAMES.filter((x) => x.slug !== g.slug && x.kind === g.kind);
  const rest = GAMES.filter((x) => x.slug !== g.slug && x.kind !== g.kind);
  return [...same, ...rest].slice(0, n);
}
```

## 3. `src/layouts/GameLayout.astro`

### 3-1. 가져오기

```ts
import { fullName, related, type Game } from '../data/games';
```

(`gamePath` 를 같이 가져온다. `homePath` 는 이미 있다.)

### 3-2. 마크업

`</div>` 로 `.gamewrap` 이 닫힌 **뒤**, `</main>` **앞**에 넣는다.

```astro
    <section class="related">
      <h2>{t.moreLike}</h2>
      <div class="relcards">
        {near.map((r) => (
          <a class="relcard" href={gamePath(lang, r.slug)}>
```

## 하지 말 것

- **대문을 갈래로 나누지 않는다.** `Hub.astro` 를 건드리지 않는다
- 갈래 이름(`kindQuick` 등)을 아직 화면에 띄우지 않는다. 나중에 쓰려고 적어 두는 것뿐이다
- 햄버거 목차를 갈래로 묶지 않는다
- 게임 자바스크립트(`src/games/*/Game.astro` 의 `<script>`)를 건드리지 않는다
- `related()` 에 무작위를 넣지 않는다. 빌드할 때마다 같아야 한다
- 대표 그림은 그대로. 다시 만들 필요 없다

---

## 끝났다는 신호

- 게임 쪽 맨 아래에 **「비슷한 게임」** 칸이 있고 카드 **두 장**이 나온다
- 몽글 과일과 쭉쭉 구슬처럼 같은 갈래가 없는 게임도 **두 장이 다 나온다**
  (같은 갈래가 모자라면 다른 갈래에서 채우게 되어 있다)
- 카드는 대문 카드와 같은 꼴 — 잉크 테두리, 밀린 그림자, 누르면 내려감
- 나라말이 유지된다 — `/ja/play/…` 에서 누르면 `/ja/play/…` 로 간다
