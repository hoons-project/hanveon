# 대문 목록을 「누르는 것」으로 바꾸기

## 목표

대문 목록이 지금은 큰 그림만 조용히 놓여 있어 **갤러리처럼** 보인다. 훈쓰가 「눌러야 할
것 같은 느낌이 없다」고 했다. 그림을 작게 하고 **카드마다 노란 「하기」 단추**를 붙인다.

짜임을 화면 크기에 따라 둘로 나눈다.

| 화면 | 모양 |
|---|---|
| **641px 이상** | 작은 오락기 카드가 줄지어 선다. 그림 위, 이름·설명, 맨 아래 「하기」 |
| **640px 이하** | 가로 줄. 왼쪽에 작은 그림(66px), 가운데 이름·설명, 오른쪽에 「하기」 |

왜 나누나 — 폰에서 카드꼴이면 여섯 개를 보려고 두 번 스크롤해야 한다. 가로 줄이면 거의
한 화면에 다 들어온다. 폰은 구경하는 곳이 아니라 빨리 고르고 들어가는 곳이다.

**게임 쪽은 건드리지 않는다.** 대문만이다.

## 1. `src/components/Hub.astro`

`.cards` 안의 `<a class="gcard">` 에 마지막 줄 하나를 더한다. 나머지는 그대로.

```astro
      GAMES.map((g) => (
        <a class="gcard" href={gamePath(lang, g.slug)}>
          <span class="thumb" set:html={g.art} />
          <span class="gname">{fullName(g, lang)}</span>
          <span class="gdesc">{g.desc[lang]}</span>
          <span class="go">{t.play}</span>
        </a>
      ))
```

`t.play` 는 `src/i18n/ui.ts` 에 이미 있다 (「하기」 / Play / あそぶ …). 새로 만들지 않는다.

## 2. `src/styles/global.css`

### 2-1. `:root` 주석 고치기

`--cream` `--sun` 위의 주석이 지금 「게임 쪽 캐비닛에만 쓴다. 대문에서는 쓰지 않는다」로
되어 있다. 이제 대문도 `--sun` 과 `--ink` 를 쓴다. 주석을 이렇게 바꾼다.

```css
  /* 오락기 쪽 색. 게임 노는 자리와 대문 목록 카드에 쓴다 */
  --ink:#2A3145;
  --cream:#FFF7EA;
  --sun:#FFD23F;
```

(`--cream` 은 여전히 게임 쪽에서만 쓴다. 대문은 `--ink` 와 `--sun` 만.)

### 2-2. 「게임 격자」 덩어리를 통째로 갈아 끼우기

지금 `/* ── 게임 격자 ── */` 부터 `.gcard:focus-visible{…}` 까지를 아래로 바꾼다.

```css
/* ── 게임 목록 ─────────────────────────────────────
   넓으면 작은 오락기 카드, 폰이면 가로 줄. 아래 좁은 화면 칸을 같이 본다. */
.rowhead{ margin:40px 0 20px }
.rowhead h2{ font-size:22px;font-weight:500;letter-spacing:-0.02em }

.cards{
  display:grid;
  grid-template-columns:repeat(auto-fill,minmax(158px,1fr));
  gap:18px;
}

.gcard{
  display:flex;
  flex-direction:column;
  background:var(--white);
  border:3px solid var(--ink);
  border-radius:16px;
  box-shadow:0 5px 0 var(--ink);
  padding:10px;
  transition:transform .07s, box-shadow .07s;
}
.gcard:active{ transform:translateY(5px); box-shadow:0 0 0 var(--ink) }
@media (hover:hover){
  .gcard:hover{ transform:translateY(-2px); box-shadow:0 7px 0 var(--ink) }
}
.gcard:focus-visible{ outline:2px solid var(--ink);outline-offset:4px;border-radius:18px }

.thumb{
  display:block;
  aspect-ratio:1/1;
  border:2px solid var(--ink);
  border-radius:10px;
  overflow:hidden;
  background:var(--faint);
}
.thumb svg{display:block;width:100%;height:100%}

.gcard .gname{
  display:block;
  margin-top:9px;
  font-size:15px;font-weight:800;line-height:1.25;letter-spacing:-0.02em;
}
.gcard .gdesc{
  display:-webkit-box;
  margin-top:3px;
  font-size:12px;color:var(--foggy);
  -webkit-line-clamp:2;line-clamp:2;-webkit-box-orient:vertical;overflow:hidden;
  flex:1;
}

/* 카드마다 붙는 노란 단추. 「여기 눌러」를 말해 주는 조각이다 */
.go{
  display:block;
  margin-top:10px;
  text-align:center;
  background:var(--sun);color:var(--ink);
  border:3px solid var(--ink);
  border-radius:11px;
  font-size:13.5px;font-weight:800;
  padding:7px 0;
}
```

**지운 것 하나** — `@media (hover:hover){ .gcard:hover .thumb{ filter:brightness(.96) } }`
는 없앤다. 이제 카드 전체가 뜬다.

### 2-3. 좁은 화면 칸 고치기

맨 아래 `@media (max-width:600px)` 덩어리에서 **`.cards{grid-template-columns:repeat(2,1fr);gap:24px 16px}` 줄을 지운다.**
(아래에 640px 칸이 새로 생겨서 이 줄은 필요 없다.)

그리고 파일 맨 끝에 아래 덩어리를 새로 더한다.

```css
/* ── 폰 — 목록을 가로 줄로 ──────────────────────────
   카드꼴이면 여섯 개 보는 데 스크롤이 두 번 걸린다. 가로 줄이면 거의 한 화면에 들어온다. */
@media (max-width:640px){
  .cards{ grid-template-columns:minmax(0,1fr); gap:12px }

  .gcard{
    display:grid;
    align-items:center;
    grid-template-columns:66px minmax(0,1fr) auto;
    grid-template-areas:
      "art name btn"
      "art desc btn";
    column-gap:13px;
    border-radius:18px;
    padding:11px 13px;
  }
  .thumb{
    grid-area:art;
    width:66px;height:66px;
    aspect-ratio:auto;
    border-width:3px;border-radius:15px;
  }
  .gcard .gname{ grid-area:name; margin-top:0; font-size:16.5px }
  .gcard .gdesc{ grid-area:desc; margin-top:2px; font-size:12.5px; flex:none }
  .go{
    grid-area:btn;
    margin-top:0;
    border-radius:12px;
    font-size:14px;
    padding:7px 11px;
    white-space:nowrap;
  }
}
```

## 3. `design/README.md`

### 3-1. 「그림자」 칸

지금 이렇게 되어 있다.

```
**거의 안 쓴다.** 목록 칸에는 **그림자도 테두리도 안 준다.** 흰 바탕과 그림만으로 나뉜다.
```

아래로 바꾼다.

```
**거의 안 쓴다.** 딱 두 군데만 쓴다 — 덮개 화면의 부드러운 그림자와,
**오락기 쪽의 딱 떨어지는 밀린 그림자**(게임 노는 자리, 대문 목록 카드).
```

그리고 그 아래 표에 한 줄을 더한다.

```
| 오락기 (게임 통 · 대문 카드 · 노란 단추) | `8px 8px 0` · `0 5px 0` — 흐림 없이 |
```

### 3-2. 「짜임」 칸

`- 대문 — 쪽 제목 → 한 줄 설명 → **게임 격자**(…)` 줄을 아래 둘로 바꾼다.

```
- 대문(넓은 화면) — 쪽 제목 → 한 줄 설명 → **작은 오락기 카드 격자**.
  카드마다 노란 「하기」 단추가 붙는다
- 대문(640px 이하) — 같은 카드가 **가로 줄**로 바뀐다. 왼쪽 작은 그림, 오른쪽 「하기」
```

### 3-3. 「게임 안쪽 — 여기는 다르다」 표

`| 머리·발·대문 목록·읽을 글 | **흰 벽** |` 줄을 아래로 바꾸고, 그 아래 줄 하나를 더한다.

```
| 머리·발·읽을 글 | **흰 벽** (이 문서 위쪽) |
| 대문 목록 카드 | **흰 벽 + 오락기 테두리** — 잉크 테두리와 밀린 그림자, 노란 「하기」 단추 |
```

### 3-4. 「색」 칸

`크림 #FFF7EA 과 해 #FFD23F 는 **게임 쪽 노는 자리에만** 쓴다. 대문에는 안 쓴다.` 줄을
아래로 바꾼다.

```
크림 `#FFF7EA` 은 **게임 쪽 노는 자리에만** 쓴다.
해 `#FFD23F` 와 잉크 `#2A3145` 는 게임 쪽과 **대문 목록 카드**에 쓴다.
```

## 하지 말 것

- **게임 쪽을 건드리지 않는다** — `src/styles/game.css`, `GameLayout.astro`,
  `src/games/*` 전부 그대로
- `src/i18n/ui.ts` 를 고치지 않는다. `t.play` 는 이미 있다
- `src/data/games.ts` 를 고치지 않는다
- 대표 그림(`public/og/`)과 `scripts/make-og.mjs` 는 그대로. 대표 그림 생김새는 안 바뀐다
- 머리(`.topbar`)와 발(`.foot`)은 그대로
- 새 CSS 변수를 만들지 않는다

## 끝났다는 신호

`/ko/` 를 열었을 때 —

- 넓은 화면(1280px): 카드 여섯 장이 한 줄에 늘어서고, 카드마다 **노란 「하기」 단추**가
  맨 아래에 있다. 카드에 잉크 테두리와 아래로 밀린 그림자가 있다
- 마우스를 올리면 카드가 살짝 뜨고, 누르면 아래로 내려간다
- 폰 크기(390px): 같은 카드가 **가로 줄**로 바뀐다. 왼쪽에 작은 그림, 오른쪽에 「하기」.
  여섯 개가 거의 한 화면에 들어온다
- **게임 쪽은 하나도 안 바뀌었다**
