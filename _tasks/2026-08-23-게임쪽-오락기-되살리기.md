# 게임 쪽만 오락기 캐비닛으로 되살리기

## 목표

**대문은 지금처럼 조용한 흰 벽 그대로 두고, 게임 쪽 노는 자리만 옛 오락기 캐비닛으로
되돌린다.** 크림색 통에 두꺼운 잉크 테두리, 딱 떨어지는 밀린 그림자, 노란 단추.

배경은 흰색 그대로다. 점무늬도 안 돌아온다.

왜 — 훈쓰가 「지난 디자인이 게임적인 느낌은 더 나았다. 배경은 깔끔하면서 안 되나」라고 했다.
대문까지 테두리를 치면 게임이 늘어날수록 목록이 시끄러워져서, **고르는 곳은 차분하게,
노는 곳은 오락기로** 나눴다.

---

## 손댈 파일

고칠 것 셋. **새로 만들 파일은 없다.**

1. `src/styles/global.css`
2. `src/styles/game.css`
3. `design/README.md`

---

## 1. `src/styles/global.css` — 색 두 개 되살리기

`:root` 안에 `--ink` 가 이미 있다. 그 바로 아래에 두 줄을 더한다.

```css
  /* 캔버스 안쪽에서 쓰는 잉크색. 게임 그림에만 쓴다 */
  --ink:#2A3145;
  /* 게임 쪽 캐비닛에만 쓴다. 대문에서는 쓰지 않는다 */
  --cream:#FFF7EA;
  --sun:#FFD23F;
```

`:root` 말고는 이 파일을 건드리지 않는다.

---

## 2. `src/styles/game.css` — 캐비닛 되살리기

### 2-1. 노는 자리를 통에 담는다

`.gamewrap` 규칙 **바로 아래**에 넣는다.

```css
/* 노는 자리는 오락기다. 대문은 흰 벽 그대로 — design/README.md 참고 */
.play{
  background:var(--cream);
  border:4px solid var(--ink);
  border-radius:24px;
  box-shadow:8px 8px 0 var(--ink);
  padding:14px;
}
```

### 2-2. 캔버스에 테두리

지금 `canvas` 규칙에서 `border-radius:12px` 를 아래처럼 바꾼다. 나머지 줄은 그대로.

```css
canvas{
  display:block;
  width:100%;
  aspect-ratio:360/620;
  border:4px solid var(--ink);
  border-radius:16px;
  touch-action:none;
  cursor:pointer;
}
```

### 2-3. HUD

지금 `.hud` 덩어리를 아래로 갈아 끼운다.

```css
.hud{
  display:grid;grid-template-columns:1fr 1fr 1fr;
  background:#fff;
  border:3px solid var(--ink);
  border-radius:14px;
  overflow:hidden;
  margin-bottom:12px;
}
.hud div{ padding:10px 8px 12px;text-align:center }
.hud div + div{ border-left:3px solid var(--ink) }
.hud b{ display:block;font-size:12px;font-weight:600;color:var(--foggy) }
.hud i{
  display:block;font-style:normal;
  font-size:20px;font-weight:800;line-height:1.2;
  font-variant-numeric:tabular-nums;letter-spacing:-0.02em;
  margin-top:2px;
}
.hud i.word{font-size:17px}
```

### 2-4. 덮개 화면 카드

`.card` 규칙만 아래로 바꾼다. `.card h2` `.card p` `.card button` 은 그대로 둔다.

```css
.card{
  width:100%;max-width:290px;
  background:var(--cream);
  border:4px solid var(--ink);
  border-radius:20px;
  box-shadow:6px 6px 0 rgba(0,0,0,.3);
  padding:24px 20px;
  text-align:left;
}
```

### 2-5. 단추 — 노랗게, 누르면 내려가게

**이 파일 안에서만** 바꾼다. `global.css` 의 `button` 은 손대지 않는다
(대문에는 단추가 없어서 지금은 차이가 안 나지만, 나중에 대문에 단추가 생기면 흰 벽 쪽을
따라야 한다).

`.pad` 규칙 위에 넣는다.

```css
/* 게임 쪽 단추만 오락기 노란 단추다 */
.play button{
  background:var(--sun);
  color:var(--ink);
  border:3px solid var(--ink);
  box-shadow:0 4px 0 var(--ink);
  font-weight:700;
  transition:transform .06s, box-shadow .06s;
}
.play button:hover{ background:var(--sun) }
.play button:active{ transform:translateY(4px); box-shadow:0 0 0 var(--ink) }
```

그리고 지금 `.pad button` 규칙의 `background:var(--faint)` 를 `background:#fff` 로 바꾸고,
`.pad button:hover{background:var(--bebe)}` 줄은 지운다.

## 3. `design/README.md` — 기준을 고쳐 적는다

「게임 안쪽 — 여기는 다르다」 칸의 표를 아래로 바꾼다.

```
| 어디 | 어느 쪽 생김새 |
|---|---|
| 머리·발·대문 목록·읽을 글 | **흰 벽** (이 문서 위쪽) |
| 게임 쪽 노는 자리 — 통·HUD·캔버스 테두리·덮개 화면·단추 | **장난감 오락기** |
| `<canvas>` 안에 그리는 것 전부 | **장난감 오락기** |
```

그 표 아래에 한 문단을 더한다.

```
**2026-08-23에 경계를 한 번 옮겼다.** 처음에는 캔버스 안쪽만 오락기로 뒀는데,
게임 쪽이 너무 밋밋했다. 그래서 **노는 자리를 담는 통까지** 오락기로 되돌렸다.
대문은 안 건드렸다 — 게임이 늘어날수록 목록에 테두리가 많아지면 시끄러워진다.
```

그리고 「색」 칸 아래에 한 줄을 더한다.

```
크림 `#FFF7EA` 과 해 `#FFD23F` 는 **게임 쪽 노는 자리에만** 쓴다. 대문에는 안 쓴다.
```

## 하지 말 것

- **대문을 건드리지 않는다** — `src/components/Hub.astro`, `.cards` `.gcard` `.thumb`
  `.more` `.lang` `.topbar` `.foot` 관련 CSS 전부 그대로
- `global.css` 의 `button` 규칙을 바꾸지 않는다 (게임 쪽은 `.play button` 으로 따로 준다)
- 게임 자바스크립트, `src/games/*/Game.astro`, `strings.ts` 는 한 글자도 안 건드린다
- 대표 그림(`public/og/`)과 `scripts/make-og.mjs` 는 그대로 둔다. 대문 생김새가 안 바뀌므로
  다시 만들 필요가 없다
- 새 CSS 변수를 더 만들지 않는다. 위에 적은 `--cream` `--sun` 둘뿐이다

---

## 끝났다는 신호

`npm run dev` 로 `/ko/play/hoppy-jump/` 를 열었을 때 —

- 게임이 **크림색 통** 안에 들어가 있고, 통에 두꺼운 잉크 테두리와 오른쪽 아래로 밀린
  그림자가 있다
- HUD 세 칸이 잉크색 줄로 나뉘어 있다
- 「시작」 단추가 **노랗고**, 누르면 아래로 내려간다
- `/ko/` 대문은 **하나도 안 바뀌었다**

## 확인 차례

```bash
npm run build
```

빌드가 통과한 뒤 브라우저로 본다.

- [ ] `/ko/play/hoppy-jump/` — 크림 통 · 잉크 테두리 · 밀린 그림자 · 노란 단추
- [ ] `/ko/` — 지금과 똑같다 (흰 바탕, 테두리 없는 목록)
- [ ] 폰 크기(390px 안팎)에서 통의 그림자가 화면 밖으로 안 잘린다
- [ ] 게임 여섯 개를 다 열어 본다 — 캔버스 바탕색이 통의 크림색과 안 부딪히는지
      (특히 `merge-fruit` 은 캔버스가 `#FFE8D2` 라 크림과 가깝다. 테두리가 4px 이라
      구분은 되지만 눈으로 한 번 본다)
- [ ] 덮개 화면(시작·끝·멈춤) 세 개가 다 크림 카드로 나온다
- [ ] 콘솔에 오류가 없다

다 되면 커밋하고 민다.

git add -A
git commit -m "게임 쪽만 오락기 캐비닛으로 — 대문은 흰 벽 그대로"
