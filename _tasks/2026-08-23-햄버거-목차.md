# 머리에 햄버거 목차 넣기

> **앞 지시서(`2026-08-23-대문-카드-오락기.md`)를 먼저 끝내고 이걸 한다.**

## 목표

머리 오른쪽에 둥근 **햄버거 단추**를 넣고, 누르면 게임 목록이 떨어지게 한다.

왜 — 지금 게임 쪽에서 다른 게임으로 가려면 「게임 목록」으로 돌아갔다가 다시 골라야 한다.
**진짜 값은 게임 쪽에 있다.** 노는 중에 바로 다른 게임으로 넘어간다.
단계 6에서 개인정보·약관·소개·연락 쪽이 생기면 그것도 여기 들어간다.

## 1. `src/i18n/ui.ts` — 글 두 개

`UiKey` 에 두 줄을 더한다 (`tipsTitle` 뒤, 세미콜론 자리를 옮긴다).

```ts
  | 'tipsTitle'    // 게임 쪽 읽을 글 — 요령
  | 'menuLabel'    // 햄버거 단추의 이름 (읽어주는 장치가 읽는다)
  | 'menuGames';   // 목차 안 「게임」 머리말
```

여섯 나라말 덩어리마다 `tipsTitle` 줄 **뒤에** 아래를 넣는다.

| 나라말 | `menuLabel` | `menuGames` |
|---|---|---|
| en | `Menu` | `Games` |
| ko | `메뉴` | `게임` |
| ja | `メニュー` | `ゲーム` |
| es | `Menú` | `Juegos` |
| fr | `Menu` | `Jeux` |
| zh | `菜单` | `游戏` |

## 2. `src/components/Menu.astro` — 새로 만든다

```astro
---
/*
  머리 오른쪽 햄버거 목차.

  지금은 게임 목록만 들어 있다. 단계 6에서 개인정보·쿠키·약관·소개·연락이 생기면
  아래에 한 덩어리를 더 붙인다.
*/
import { GAMES, fullName } from '../data/games';
import { gamePath, type Lang } from '../i18n';
import { ui } from '../i18n/ui';

interface Props {
  lang: Lang;
  /** 게임 쪽일 때 지금 보고 있는 게임. 목차에서 표시된다. */
  slug?: string;
}
const { lang, slug } = Astro.props;
const t = ui(lang);
---

<div class="menuwrap">
  <button
    id="menuBtn"
    class="iconbtn"
    type="button"
    aria-label={t.menuLabel}
    aria-expanded="false"
    aria-controls="menuPanel"
  >
    <svg viewBox="0 0 16 16" width="16" height="16" aria-hidden="true">
      <path d="M2 4.5h12M2 8h12M2 11.5h12" fill="none" stroke="currentColor"
            stroke-width="1.6" stroke-linecap="round" />
    </svg>
  </button>

  <div id="menuPanel" class="menupanel" hidden>
    <p class="menuhead">{t.menuGames}</p>
    <ul>
      {GAMES.map((g) => (
        <li>
          <a href={gamePath(lang, g.slug)} aria-current={g.slug === slug ? 'page' : undefined}>
            <span class="mthumb" set:html={g.art} />
            {fullName(g, lang)}
          </a>
        </li>
      ))}
    </ul>
  </div>
</div>

<script>
  const btn = document.getElementById('menuBtn');
  const panel = document.getElementById('menuPanel');

  if (btn && panel) {
    const open = (on: boolean) => {
      panel.hidden = !on;
      btn.setAttribute('aria-expanded', String(on));
    };

    btn.addEventListener('click', (e) => {
      e.stopPropagation();
      open(panel.hidden);
    });

    /* 바깥을 누르면 닫는다 */
    document.addEventListener('click', (e) => {
      if (panel.hidden) return;
      if (!panel.contains(e.target as Node)) open(false);
    });

    /* Esc 로도 닫는다. 닫고 나면 단추로 초점을 돌려준다 */
    document.addEventListener('keydown', (e) => {
      if (e.key === 'Escape' && !panel.hidden) { open(false); btn.focus(); }
    });
  }
</script>
```

## 하지 말 것

- 게임 쪽(`src/styles/game.css`, `GameLayout.astro`, `src/games/*`)을 건드리지 않는다
- `src/data/games.ts` 를 건드리지 않는다
- 대문 목록 카드(`.cards` `.gcard` `.go`)를 건드리지 않는다 — 앞 지시서에서 끝냈다
- 목차에 갈래(카테고리) 나누기를 넣지 않는다. 지금은 그냥 한 줄로 쭉 나열한다
- 발(`.foot`)에 링크를 더하지 않는다. 단계 6에서 한다

---

## 끝났다는 신호

- 머리 오른쪽에 나라말 칸 옆으로 **둥근 햄버거 단추**가 있다
- 누르면 아래로 목차가 떨어지고, 게임 여섯 개가 작은 그림과 함께 나온다
- 게임 쪽에서 열면 **지금 보고 있는 게임이 눌린 것처럼 표시**된다
- 바깥을 누르거나 Esc 를 누르면 닫힌다
- 폰에서도 목차가 화면 밖으로 안 나간다
