# 대표 그림 66장 다시 만들기 — 게임 이름이 바뀌었다

## 왜

`ac654da` (챗지피티가 다듬은 커밋) 에서 **게임 열 개의 이름이 여섯 나라말 전부 바뀌었다.**
그런데 `public/og/` 의 그림 66장은 **그 전 커밋(`20ab3b0`) 그대로**다.

지금 이렇게 어긋나 있다 —

| 어디 | 지금 나오는 글 |
|---|---|
| `hanveon.com/ko/play/hoppy-jump/` 제목 | 점프 클라이머 |
| `public/og/hoppy-jump-ko.png` 안의 글 | **폴짝 점프** |

카톡·트위터에 링크를 붙이면 **옛 이름이 그대로 뜬다.**

## 먼저 할 것

맥북이 GitHub 보다 한 커밋 뒤처져 있다.

```bash
git pull
git log --oneline -1     # ac654da 가 나와야 한다
```

## 할 일

```bash
node scripts/make-og.mjs
npm run build
```

`make-og.mjs` 가 66장(게임 10 × 6 + 대문 6)을 다시 만든다.
`scripts/og-data.ts` 가 `src/data/games.ts` 를 그대로 읽으므로 새 이름이 들어간다.

## 확인 차례

1. `npm run build` 통과
2. **그림을 눈으로 연다** — 아래 넷을 열어서 이름이 새것인지 본다
   - `public/og/hoppy-jump-ko.png` → 「점프 클라이머」
   - `public/og/pop-shot-en.png` → 「360 Shot」
   - `public/og/tidy-tubes-ja.png` → 「カラー ソート」
   - `public/og/home-ko.png` → 게임 그림 10개가 안 잘리고 다 보이는지
3. 66장이 다 바뀌었는지 — `git status --short public/og/ | wc -l` 이 **66**

## 하지 말 것

- `src/data/games.ts` 의 이름을 되돌리지 않는다. 새 이름이 맞다
- 주소(`slug`)는 **그대로 둔다.** `hoppy-jump` 는 계속 `hoppy-jump` 다.
  이미 구글에 올라간 주소라 바꾸면 그동안 쌓인 것이 끊긴다
- `make-og.mjs` 의 `artsLayout()` 을 건드리지 않는다 (`c08902b` 에서 고친 곳)

## 끝났다는 신호

커밋해서 밀고, 몇 분 뒤 카톡에 `https://hanveon.com/ko/play/hoppy-jump/` 를 붙여
**「점프 클라이머」** 가 뜨면 끝이다.
(카톡이 그림을 캐시해 둬서 옛것이 뜰 수 있다. 그때는 주소 끝에 `?v=2` 를 붙여 본다.)
