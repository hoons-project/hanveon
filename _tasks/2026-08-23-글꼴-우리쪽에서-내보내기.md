# 글꼴을 구글에서 안 받고 우리 쪽에서 내보내기

> **단계 6의 첫 조각.** 개인정보 쪽을 쓰기 전에 이것부터 한다.

## 목표

지금 `BaseLayout.astro` 가 글꼴을 **`fonts.googleapis.com` 에서 받아온다.**
그러면 방문자 브라우저가 구글에 직접 요청을 보내고, **방문자 IP가 구글로 넘어간다.**

2022년 독일 뮌헨 법원이 이것을 유럽 개인정보법(GDPR) 위반으로 판결했다
(사건 3 O 17493/20, 사람당 100유로 배상). hanveon 은 프랑스말·스페인말 쪽이 있어
유럽 방문자를 받으므로 남의 일이 아니다.

**개인정보 쪽에 「우리는 아무것도 안 모읍니다」라고 쓰려면 먼저 실제로 그래야 한다.**
지금 상태로 그렇게 쓰면 거짓말이 된다.

고치는 법 — 글꼴 파일을 저장소 꾸러미로 받아서 **우리 사이트에서 내보낸다.**
바깥으로 나가는 요청이 0이 된다.

> 이 방법은 지시서를 쓴 쪽에서 **실제로 넣고 빌드해서 확인했다.**
> 구글로 나가는 요청 0개, 글꼴 파일 7개가 `dist/_astro/` 에 들어가고, 빌드가 통과한다.

---

## 손댈 파일

1. `package.json` — 꾸러미 하나 더하기 (`npm i` 로)
2. `src/layouts/BaseLayout.astro` — 구글 링크 셋 지우고 가져오기 한 줄
3. `src/styles/global.css` — 글꼴 이름 한 군데
4. `design/README.md` — 「글씨」 칸 한 줄
5. `CLAUDE.md` — 「생김새를 2026-08-22에 통째로 바꿨다」 칸 한 줄

---

## 1. 꾸러미 더하기

```bash
npm i @fontsource-variable/inter
```

`package.json` 의 `dependencies` 에 들어간다. `devDependencies` 가 아니다 —
빌드할 때 글꼴 파일이 필요하다.

`@fontsource-variable/inter` 는 Inter 를 **가변 글꼴**(굵기를 하나의 파일로 다루는 글꼴)
하나로 담고 있어서, 굵기 400·500·600·700·800 을 따로 받을 필요가 없다.
Inter 는 SIL 오픈 폰트 라이선스라 우리 쪽에서 내보내도 된다.

---

## 2. `src/layouts/BaseLayout.astro`

### 2-1. 맨 위 가져오기에 한 줄

```ts
import '@fontsource-variable/inter/wght.css';
import '../styles/global.css';
```

`wght.css` 는 굵기만 다루는 것이다. 기울임과 시각 크기(`opsz`)는 안 쓰므로 안 가져온다.
나라말별 글자 묶음마다 `unicode-range` 가 붙어 있어서 **브라우저가 필요한 것만 받는다.**

### 2-2. 구글 링크 셋을 지운다

`<head>` 안의 이 덩어리를 **통째로 지운다.**

```astro
    {/* 글씨 — Inter. 한글·일본말·중국말은 기기에 있는 글꼴이 받는다 */}
    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
    <link
      rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap"
    />
```

---

## 3. `src/styles/global.css`

`body` 의 `font-family` 맨 앞에 `"Inter Variable"` 을 넣는다.
꾸러미가 만드는 글꼴 이름이 `Inter` 가 아니라 **`Inter Variable`** 이다.

```css
  font-family:"Inter Variable","Inter","Pretendard","Apple SD Gothic Neo","Hiragino Sans",
              "Noto Sans KR","Noto Sans JP","PingFang SC",system-ui,sans-serif;
```

뒤의 `"Inter"` 는 그대로 둔다 — 기기에 Inter 가 깔려 있으면 그것도 받아 준다.
한글·일본말·중국말은 여전히 뒤 차례가 받는다. **Inter 에는 한글이 없다.**

---

## 4. `design/README.md`

「글씨」 칸 첫 줄을 아래로 바꾼다.

```
- 차례 — `Inter Variable` → `Pretendard` → 시스템 글꼴.
  Inter 는 **우리 저장소에서 내보낸다** (`@fontsource-variable/inter`).
  **구글 글꼴 주소에서 받아오지 않는다** — 방문자 IP가 구글로 넘어가서 유럽 개인정보법에
  걸린다. 한글·일본말·중국말은 뒤 차례가 받는다
```

## 5. `CLAUDE.md`

「생김새를 2026-08-22에 통째로 바꿨다」 칸에서 이 줄을

```
- 글꼴로 **Inter** 를 구글 글꼴에서 받는다 (`BaseLayout.astro`).
  한글·일본말·중국말은 기기에 있는 글꼴이 받는다
```

아래로 바꾼다.

```
- 글꼴로 **Inter** 를 쓴다. **우리 저장소에서 내보낸다** (`@fontsource-variable/inter`).
  2026-08-23에 구글 글꼴 주소에서 받아오던 것을 바꿨다 — 방문자 IP가 구글로 넘어가서
  유럽 개인정보법에 걸린다. **바깥에서 받아오는 것을 새로 넣지 않는다**
```

---

## 하지 말 것

- 글꼴 파일을 손으로 받아서 `public/` 에 넣지 않는다. 꾸러미로 받는다
- `index.css` 를 가져오지 않는다. 기울임까지 다 들어와서 무거워진다. `wght.css` 만
- 글꼴 차례에서 한글·일본말·중국말 글꼴 이름을 지우지 않는다. Inter 에는 그 글자가 없다
- 다른 바깥 주소(분석 도구, 아이콘 꾸러미 등)를 새로 넣지 않는다
- 대문·게임 쪽 짜임은 건드리지 않는다

---

## 끝났다는 신호

- 페이지 소스에 `fonts.googleapis.com` 과 `fonts.gstatic.com` 이 **한 군데도 없다**
- 글씨 생김새는 눈으로 봐서 전과 같다
- 브라우저 개발자 도구의 네트워크 칸에서 **구글로 나가는 요청이 0개**다

---

## 확인 차례

```bash
npm run build
```

**바깥으로 나가는 것이 정말 없는지 센다.**

```bash
grep -rn "fonts.googleapis\|fonts.gstatic" dist/ | wc -l     # 0 이어야 한다
find dist -name "*.woff2" | wc -l                            # 7 쯤 나온다
```

- [ ] 위 두 줄이 각각 `0` 과 `7`(언저리)인지
- [ ] `/` `/ko/` `/ja/` `/zh/` 를 열어 글씨가 전과 같은지 —
      특히 **한글·일본말·중국말이 네모(두부)로 안 나오는지**
- [ ] 브라우저 네트워크 칸에서 `google` 로 나가는 요청이 없는지
- [ ] 숫자가 여전히 자릿수 안 흔들리게 나오는지 (HUD)
- [ ] 콘솔에 오류가 없다

다 되면 커밋하고 민다.

```
git add -A
git commit -m "글꼴을 우리 쪽에서 내보내기 — 구글로 IP가 안 나가게"
git push
```
