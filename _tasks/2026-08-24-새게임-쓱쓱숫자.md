# 새 게임 — 쓱쓱 숫자 (`slide-tiles`)

> **글은 이미 들어와 있다.** `src/games/slide-tiles/strings.ts` 에 여섯 나라말이 다 있다.
> **한 글자도 고치지 않는다.**
>
> `design/new-game-checklist.md` 를 옆에 놓고 그 차례를 따른다.
>
> **이걸로 게임이 열 개가 된다.** 단계 7의 마지막이다.

## 목표

4×4 판에서 한쪽으로 쓸면 칸이 다 그쪽으로 밀리고, **붙은 같은 수 둘이 두 배짜리 하나**가 된다.
움직인 뒤에는 늘 새 숫자가 하나 나온다. 자리가 없고 붙일 것도 없으면 끝.

## 왜 이 게임인가

지금 아홉 개 중 **여섯이 순발력 게임**이다. 이걸 넣으면 순발력 6 · 생각하는 2 · 쌓고 합치기 2 가 되어
대문을 갈래로 나눌 수 있을 만큼은 고르게 된다.

**규칙을 다들 이미 안다.** 설명 없이 바로 시작할 수 있는 게 이 게임의 값이다.

**몽글 과일과 겹치지 않는다** — 몽글 과일은 떨어뜨려서 물리로 붙이는 것이고,
이건 판을 밀어서 자리를 짜는 것이다. 손가락은 비슷해도 머리로 하는 일이 다르다.

## 3. 화면 짜임 — 캔버스 360×620

| 무엇 | 자리 |
|---|---|
| 바탕 | `#F0EDE8` (따뜻한 회색) |
| 판 | 4×4. 칸 74px, 사이 10px → `4×74 + 5×10 = 346px` |
| 판 왼쪽 위 | `(7, 150)` — 판이 세로 가운데쯤 온다 |
| 빈 칸 | `#E2DDD6`, 모서리 10 |
| 숫자 칸 | 아래 색 표. 잉크 테두리 2.5px, 모서리 10 |

| 수 | 바탕 | 글씨 |
|---|---|---|
| 2 | `#FFF7EA` | 잉크 `#2A3145` |
| 4 | `#FFE9C7` | 잉크 |

## 4. 규칙 — 정확히 이대로

```js
const N = 4;            // 4×4
const NEW_FOUR = 0.10;  // 새 숫자가 4일 확률. 나머지는 2
```

**한 번 미는 것**

1. 고른 방향으로 줄마다 칸을 몰아붙인다 (빈 칸을 없앤다)
2. 그 줄에서 **붙은 같은 수 둘**을 앞쪽부터 합친다. **한 번 민 동안 같은 칸은 한 번만 합쳐진다**
   (예 — `2 2 4` 를 왼쪽으로 밀면 `4 4` 이지 `8` 이 아니다)
3. 다시 몰아붙인다
4. **뭔가 달라졌으면** 빈 칸 하나를 골라 새 숫자를 놓는다. **아무것도 안 달라졌으면 새 숫자도 없다**

**점수** — 합칠 때마다 **합쳐서 나온 수**만큼 더한다 (`2+2` → `+4`).
합친 자리에 `T.gain.replace('{n}', 나온수)` 를 띄운다.

**끝** — 빈 칸이 없고, 위아래·좌우로 붙은 같은 수도 없을 때.

**2048** — 처음 만들면 `T.bigOne` 을 크게, 그 밑에 `T.keepGoing` 을 한 번 띄운다.
**게임은 안 끝난다.** 그대로 이어서 한다. 한 판에 한 번만 띄운다.

## 7. 움직임

- 미는 것은 **0.12초** 안에 끝낸다. 칸이 미끄러져 가는 것이 보여야 어디로 갔는지 안다
- 합쳐진 칸은 잠깐 **1.15배**로 커졌다 돌아온다
- 새로 나온 칸은 **0에서 1로** 커진다
- `prefers-reduced-motion` 이 켜져 있으면 **미끄러짐 없이 바로 자리 잡게** 한다

## 하지 말 것

- **`strings.ts` 를 고치지 않는다.** 이상하면 알려 달라
- 4번 규칙과 숫자, 3번 색 표를 바꾸지 않는다
- 2048에서 게임을 끝내지 않는다
- **되돌리기를 넣지 않는다.** 톡톡 정리가 그걸 쓴다. 여기는 안 쓴다
- 시간 제한을 넣지 않는다
- 바깥 CSS 를 새로 쓰지 않는다
- 게임 안에 `LANGS` `pickLang()` `apply()` 를 만들지 않는다
- 게임 코드 안에 `T` 라는 이름의 다른 변수를 두지 않는다
- `<style>` 과 `<script>` 는 **`</GameLayout>` 안쪽 맨 끝**에 둔다

---

## 끝났다는 신호

- 여섯 주소가 다 열린다
- 쓸면 칸이 그쪽으로 밀리고 같은 수가 합쳐진다
- **`2 2 4` 를 왼쪽으로 밀면 `4 4` 다** (`8` 이면 틀렸다)
- 아무것도 안 움직이는 방향으로 밀면 **새 숫자가 안 나온다**
- 판이 꽉 차고 붙일 것도 없으면 끝 화면
- 2048을 만들어도 안 끝난다

## 확인 차례

```bash
npm run build
node scripts/make-og.mjs
npm run build
```

**미는 셈이 맞는지 잰다.** 게임을 헤드리스로 돌려서, 판을 정해 놓고 한 번씩 밀어 본다.

| 왼쪽으로 밀기 전 (한 줄) | 밀고 나서 |
|---|---|
| `2 2 4 -` | `4 4 - -` |
| `2 2 2 2` | `4 4 - -` |
| `4 4 8 8` | `8 16 - -` |
| `2 - 2 4` | `4 4 - -` |
| `4 2 2 4` | `4 4 4 -` |
| `- - - 2` | `2 - - -` |

**`2 2 2 2` → `4 4` 이지 `8` 이 아니다.** 이 줄이 제일 잘 틀리는 곳이다.

**새 숫자 비율을 센다.**

```
빈 판에서 5000번 새 숫자를 뽑아 2와 4의 비율을 센다. 2 가 90% 언저리여야 한다.
```

**안 움직이는 방향에 새 숫자가 안 나오는지 본다.**

```
한 줄이 꽉 차고 합칠 것도 없는 판을 만든 뒤 그 방향으로 민다.
칸 수가 늘면 안 된다.
```

**「비슷한 게임」 받는 링크를 센다.** 게임이 열이 된다.

```bash
node -e '
const fs=require("fs");
const S=["hoppy-jump","zoom-drive","merge-fruit","zippy-plane","pop-shot","chain-dots","spot-kick","long-pass","tidy-tubes","slide-tiles"];
const inn={}; S.forEach(s=>inn[s]=0);
for (const s of S){
  const h=fs.readFileSync(`dist/play/${s}/index.html`,"utf8");
  const m=[...h.matchAll(/class="relcard" href="\/play\/([a-z-]+)\//g)].map(x=>x[1]);
  console.log(s,"→",m.join(" · "));
  m.forEach(t=>inn[t]++);
}
console.log("받는 링크:",inn);
'
```

**대문 대표 그림을 꼭 눈으로 연다.** 게임이 열이 되면 한 줄에 다섯씩 두 줄이 된다.

```bash
find public/og -name "slide-tiles-*.png" | wc -l   # 6
grep -o "<url>" dist/sitemap-0.xml | wc -l         # 90 → 96
```
